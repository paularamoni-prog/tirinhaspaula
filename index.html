Toque num texto da tirinha para começar
Como usar: toque no texto para editá-lo — agora é uma única caixa por tirinha, use Enter para quebrar linha dentro dela. A alteração é copiada para as outras tirinhas. Para mudar fonte, tamanho, espaçamento entre linhas, negrito ou itálico: selecione um trecho e use a barra acima; sem seleção, o ajuste vale para a caixa inteira. Segure a bolinha azul no canto da caixa para movê-la. Para redimensionar: bolinha verde-água na lateral muda só a largura, bolinha roxa embaixo muda só a altura, e a bolinha laranja no canto muda as duas juntas. Toque nas imagens (logo à esquerda, ilustração à direita) para trocá-las. Em Compartilhar você gera o PDF e envia direto para WhatsApp, Drive, e-mail ou qualquer app do aparelho.
